This is a simple and responsive team profile webpage built with **HTML**, **CSS**, and **JavaScript**.

> Showcase your amazing team with a clean modern design!

---

## Project Structure
```
team-website/
│
├── index.html       # Main HTML file
├── style.css        # Stylesheet for layout and design
├── script.js        # JavaScript file for interactivity
├── images/
│   ├── Person1.jpg  # Team Member 1 photo
│   └── Person2.jpg  # Team Member 2 photo
```

## Features
- Fully responsive layout
- Clean card design with hover effects
- Smooth scaling on hover
- Easy to add more team members
- Organized code structure

## How to Upload Online for Free

### 1. Using **GitHub Pages**
- Create a new GitHub repository (e.g., `team-website`).
- Upload all files (`index.html`, `style.css`, `script.js`, and `images/` folder).
- Go to **Settings → Pages**.
- Under **Branch**, select `main` and root `/`.
- Your website will be live at:  
  `https://your-username.github.io/team-website/`

### 2. Using **Netlify**
- Go to [netlify.com](https://www.netlify.com/).
- Create a free account.
- Click **Add new site → Import an existing project**.
- Drag and drop your unzipped project folder.
- Done! Your website will be hosted for free.
